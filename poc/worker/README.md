# Worker上のCID照合 PoC

## 1. 結論

Worker 上の DID 解決・公開レコードの取得・CID 照合は、受理 1 回あたり約 3.7 ミリ秒で完了し、無料枠の CPU 時間 10 ミリ秒に収まる。

## 2. 反映先

- platform

## 3. 制約値

| 項目                                                   | 値            |
| ------------------------------------------------------ | ------------- |
| 受理 1 回あたりの CPU 時間（DID 解決・取得・CID 照合） | 約 3.7 ミリ秒 |
| CID の計算 1 件あたりの CPU 時間                       | 0.025 ミリ秒  |

## 4. 検証項目

| 仮説                                                    | 合格基準                                    | 結果 |
| ------------------------------------------------------- | ------------------------------------------- | ---- |
| Worker 上で実在する PDS のレコードの CID を再計算できる | 再計算した CID が PDS の返す CID と一致する | 合   |
| 受理 1 回の CPU 時間が無料枠に収まる                    | 10 ミリ秒以下                               | 合   |
| Cron Trigger の呼び出しとデータベースの読み書きが動く   | ローカルの実行環境で成功する                | 合   |
