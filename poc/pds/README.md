# ブラウザOAuthの書き込み権限 PoC

## 1. 結論

ブラウザの OAuth で要求した独自コレクションの権限だけが付与され、要求していないコレクションと操作は拒否される。画像のアップロードも成功する。

## 2. 反映先

- web-task

## 3. 制約値

- なし

## 4. 検証項目

| 仮説                                                        | 合格基準                                     | 結果 |
| ----------------------------------------------------------- | -------------------------------------------- | ---- |
| 独自コレクションの書き込み権限を OAuth で要求して付与される | 要求したコレクションだけに書き込める         | 合   |
| 要求していないコレクションと操作が拒否される                | Bot 側の識別子・投稿の作成・削除が拒否される | 合   |
| 画像の blob をアップロードできる                            | 画像のアップロードが成功する                 | 合   |
