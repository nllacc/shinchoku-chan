# PDSの書き込みレート制限 PoC

## 1. 結論

PDS の公式実装の書き込みレート制限では、Bot が作成できるレコードは 1 日あたり約 11600 件である。

## 2. 反映先

- platform

## 3. 制約値

| 項目                         | 値             |
| ---------------------------- | -------------- |
| 書き込みの点数の上限         | 1 時間 5000 点 |
| 書き込みの点数の上限         | 1 日 35000 点  |
| レコード 1 件の作成の点数    | 3 点           |
| 1 日に作成できるレコードの数 | 約 11600 件    |

## 4. 検証項目

| 仮説                                       | 合格基準                                    | 結果 |
| ------------------------------------------ | ------------------------------------------- | ---- |
| PDS の実装の書き込みレート制限の値が分かる | 1 時間・1 日の点数と作成 1 件の点数が分かる | 合   |
