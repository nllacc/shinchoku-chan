# 測定の記録

公式実装の PDS（@atproto/pds 0.5.38）の書き込みレート制限は、次のとおりである。

| 項目                     | 値                      |
| ------------------------ | ----------------------- |
| 1 時間あたりの点数の上限 | 5000 点                 |
| 1 日あたりの点数の上限   | 35000 点                |
| レコード 1 件の作成      | 3 点                    |
| 1 日あたりの作成件数     | 35000 ÷ 3 = 約 11600 件 |

実環境（bsky.social）の制限は、この PoC では確認していない。
